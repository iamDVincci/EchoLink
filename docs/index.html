SPECIFICATION BLUEPRINT

Zero-Cloud Wire Architecture

Every datagram on UDP port 51111 adheres to the EchoLink binary wire protocol. Hover over each byte block below to inspect its cryptographic and low-overhead structure.

UDP VOICE DATAGRAM // 21-BYTE AG HEADER + PAYLOAD + 16-BYTE POLY1305 HOVER BYTES TO INSPECT
0x41 0x47 Magic (AG)
0x02 Version
0x01 Type
[4 Bytes] SeqNum
[8 Bytes] Timestamp
[2 Bytes] Length
[640 Bytes] Voice PCM
[16 Bytes] Poly1305 Tag
MAGIC BYTES // 0x41 0x47 ("AG")
2-byte header identifier (0x4147). Validates that incoming UDP datagrams on port 51111 belong strictly to the EchoLink protocol, immediately discarding stray network packets without decrypting.
